# 小说阅读器

一个简洁优雅的中文小说阅读器，支持 Web、桌面和 Android 多平台。

## 功能特点

### 核心功能
- **智能章节识别**：自动识别"第X章"等中文章节格式
- **双模式阅读**：滚动模式和翻页模式自由切换
- **阅读进度保存**：自动记住每本书的阅读位置
- **书签系统**：支持添加书签和笔记，方便回顾

### 个性化设置
- **主题切换**：5 种护眼主题，适应不同阅读环境
- **字体调整**：支持字体大小、行高、字体样式调节
- **进度可视化**：书架显示精美阅读进度环

### 便捷操作
- **文件导入**：支持 .txt 格式小说文件导入
- **内容搜索**：全文搜索，快速定位内容
- **手势操作**：长按删除、滑动翻页、文本选择
- **键盘快捷键**：支持方向键、空格键等快捷操作

## 快速开始

### Web 版本（推荐）

1. 直接在浏览器中打开 `reader.html` 文件
2. 点击右上角 "+" 按钮导入 .txt 小说文件
3. 开始阅读！

### 桌面版本

1. 进入 `desktop` 目录
2. 运行 `npm install` 安装依赖
3. 运行 `npm start` 启动桌面应用

### Android 版本

1. 进入 `android` 目录
2. 使用 Android Studio 打开项目
3. 编译生成 APK 安装包

## 技术栈

- **前端**：纯原生 JavaScript (ES6+)，无框架依赖
- **存储**：IndexedDB + localStorage 双重存储
- **桌面**：Electron
- **移动**：Capacitor + Android
- **API**：OpenLibrary（书籍封面获取）

## 使用说明

### 导入小说
- 点击书架右上角的 "+" 按钮
- 选择 .txt 格式的小说文件
- 系统会自动识别章节和书名

### 阅读操作
- **滚动模式**：上下滚动阅读，自动保存进度
- **翻页模式**：点击屏幕左右区域翻页
- **添加书签**：选中文本后点击书签按钮
- **搜索内容**：使用搜索功能查找特定内容

### 快捷键
- `←` / `→`：上一章 / 下一章
- `↑` / `↓`：向上/向下滚动
- `空格`：向下翻页
- `Esc`：退出阅读模式

## 开发说明

### 本地开发
直接修改 `reader.html` 文件，刷新浏览器即可看到效果。

### 构建 APK
```bash
# Windows
双击运行 scripts/编译APK.bat

# 或手动执行
cd android
./gradlew assembleDebug
```

### 注意事项
- 修改代码前建议先备份 `reader.backup.html`
- 测试导入功能可使用项目中的示例小说文件
- 项目无构建步骤，修改即生效
